# Art sources

Raw, unprocessed ChatGPT-generated sprite sheets, kept as the original reference for everything in
`client/public/sprites/`. These are the full sheets before extraction/cropping/background-removal;
the actual game art is the individual PNGs in `client/public/sprites/`, wired up per `SPRITES.md`.

Useful if a sprite ever needs re-extracting at a different crop, or as style/scale reference when
prompting a new generation that should match an existing character or building.

Filenames are whatever the source saved them as (ChatGPT's own auto-naming, or a descriptive name
when generated by title). No fixed naming convention — cross-reference against `SPRITES.md`'s
"Already sourced" section to see what came from which sheet.
