THE SWORN GAME — APPROVED AUTUMN STYLE / PRODUCTION PLAN
2026-11-10

PROJECTION LOCK — USER CORRECTION 2026-11-11
X screen-horizontal, Y screen-vertical. Zero yaw. No isometric/diamond world
pieces or rotated three-quarter footprints. All building/furniture footprints,
wall runs, roofs and terrain align with these axes. Upright front elevations
stand above flat top planes. See grid-projection-contract.txt. Earlier angled
studies are color/material references only, never geometry references.

STYLE LOCK
Canonical character: hunter variation 02 (autumn tracker).
Canonical cross-category reference: autumn-style-characters-and-world.png.
Warm rust, ochre, olive, cream, leather brown and slate; dark colored outlines;
angular chunky pixel clusters; 3–4 deliberate shades per material; upper-left
light. Artistic, moderately detailed, neither realistic nor exaggerated chibi.
Use these SAME references on every generation, never successive generations
alone: that accumulates style drift. The earlier realism study is rejected.

SIZE CONTRACT
Game tile remains 32 world pixels. Current modular source art uses 64 source
pixels per tile; retain that 2:1 source/world ratio for the replacement set.
Humans target 56 source pixels / 28 world pixels from feet to head, with a
shared 96x96 source frame canvas for weapon padding. Size from the BODY rather
than the entire image bounds. Fixed foot pivot (48,88), no per-frame fitting.
Buildings follow existing footprints: a 2-tile asset spans 128 source pixels.
Tall roofs may overhang visually without changing collision. Mounted units,
large monsters and siege keep their existing relative world sizes; size them
from a per-kind manifest, never independently fit each animation frame.
Generated source sheets are candidates: exact grid and pivots must be checked
and normalized before these dimensions can be claimed as delivered.

ANIMATION CONTRACT
Keep current action names, frame counts and timing during first replacement;
do not silently change gameplay or the animation registry. Walk: contact,
passing, opposite contact, opposite passing. Attack: anticipation, impact,
recovery (archer currently has six frames; hunter has three). Carry frames
must retain the same body/feet. Idle, seated, sleep and hurt keep identity.
First hunter source has four action/carry frames for evaluation; map to the
existing three-action/two-carry contract explicitly during integration.
Existing one-facing sprites may mirror as the current renderer does. Full
four-direction sets are separately queued; never label one-facing art as 4-dir.
No animation is production-approved until a loop preview passes: no head-size
drift, swapped equipment, foot sliding, clipping, baseline jumps or color drift.

HURT / DAMAGE
Every human and monster, including players, heroes, villagers, settlement NPCs,
bandits, goblins, undead, wisps and bosses: brief crimson splash across body on
actual HP loss. A shared 4-frame effect, scaled/masked to the body, avoids a
duplicate injured version of EVERY movement/action frame. Palette: deep crimson
#731F35, main crimson #B52D46, bright accent #E34B58. Stylized, no gore.
Supplement with persistent light/medium/heavy wound overlays while injured;
clear on healing/death/hiding; preserve faction colors and status effects.
Current code has threshold wounds (<66%, <40%, <20%) for colonists/mobs;
the inspected player renderer does not call that helper. Universal hit-triggered
feedback requires code work and validation; it is NOT implemented by these sheets.
Buildings/pieces: intact, lightly damaged, heavily damaged, destroyed/breached.
Cracked stone, split timber, missing thatch/tiles, broken windows and bent metal;
preserve joins, footprint and door orientation. Use existing HP where available;
decorative pieces without HP need explicit behavior decisions before damage wiring.
Roof cutaway/ghost alpha is applied in code, not duplicated painted assets.

MINIMIZE GENERATION COUNT
Never generate one image per output PNG. Group by pixel scale and compatible
animation/state layout, cap each source atlas around 32–64 SIMPLE cells (fewer
for complex buildings/animation). Larger crowded atlases increase slicing and
identity errors. Exhaustive existing-file mapping is in sprite-production-
manifest.json and sprite-production-inventory.txt; groups automatically page
at 48 files as a planning estimate, NOT a guaranteed generation count. Final
packing must account for canvas sizes and related cycles. New missing art and
new damage states increase that count. Reuse tinted factions, modular buildings,
runtime alpha, overlays and existing template composition to avoid duplicates.
